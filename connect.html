Browser API

Use window.faultline directly

The browser API and WebMCP tools operate on the same revision-guarded canonical state.

const state = window.faultline.inspect();

const frontier = window.faultline.units({ targetAxis: 'html' });

await window.faultline.probe({
  expectedRevision: state.revision,
  targetAxis: 'html',
  unitId: frontier.units[0].id
});
