Use FAULTLINE programmatically

Top-level browser API is exposed as window.faultline. When document.modelContext exists, compatible WebMCP tools are registered in-page.
await window.faultline.inspect()
await window.faultline.run()
await window.faultline.defineOracle({ kind:'dom_property', selector:'#modal', property:'open', equals:true, action:{kind:'click',selector:'#save'} })
await window.faultline.exportCase()
